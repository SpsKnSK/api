# 💥 Pokazte to!

Skopíruj nasledujúci jednoduchý program, spusti ho a potom ho uprav podľa pokynov. Sleduj, kedy dostaneš chybové hlásenie a kedy program síce beží, ale nedá očakávaný výsledok.

```python
cislo = input("Zadaj číslo: ")
print(cislo + 12)
```

Vyskúšaj:

- Zadaj `50`. Prečo program nemôže sčítať text s číslom `12`?
- Oprav program tak, aby pri načítaní použil `int()`.
- Potom ho uprav tak, aby pomocou `float()` načítal aj desatinné číslo.
- Použi `int(input(...))`, ale namiesto čísla zadaj písmeno.
- Pri `int(input(...))` zadaj `1.5`.
- Na konci `int(input(...))` vymaž jednu zátvorku.

Prečítaj si chybové hlásenie: ako sa chyba volá, na ktorý riadok ukazuje a čo prezrádza o probléme?
