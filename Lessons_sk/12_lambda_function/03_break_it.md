# 💥 Pokazte to!

Skopíruj program, spusti ho a potom ho oprav tak, aby sa zobrazil zoznam druhých mocnín.

~~~python
numbers = [1, 2, 3, 4]
squared = map(lambda x: x**2, numbers)
print(squared)
~~~
