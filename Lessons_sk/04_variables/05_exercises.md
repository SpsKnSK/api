# Cvičenia – Premenné

## Základné úlohy

1. Vytvor po dve premenné z každého uvedeného dátového typu (`int`, `float`, `str`, `bool`) a vypíš ich pomocou funkcie `print()`.
2. Vytvor číselné premenné a vyskúšaj na nich všetky uvedené matematické operátory.
3. Pomocou funkcie `print()` vypíš výsledky aspoň piatich matematických operácií.

## Náročnejšie úlohy

4. Načítaj dve čísla, vypíš ich podiel zaokrúhlený na tri desatinné miesta, celočíselný výsledok delenia a zvyšok. Program má vypísať aj vysvetľujúci text.
   - `/`: `18 / 7 = 2.5714285714285716`
   - `//`: `18 // 7 = 2`
   - `%`: `18 % 7 = 4`
5. Napíš program na výpočet obvodu a plochy kruhu. Vstup: priemer; hodnota pí je `3.14159`. Vzor: `Kruh s priemerom X cm má obvod Y cm a plochu Z cm².`
6. Načítaj dve celé čísla, dve desatinné čísla a potom dve komplexné čísla. Pri každej dvojici vypíš súčet a súčin.
   - `int(input())` – celé číslo
   - `float(input())` – desatinné číslo
   - `complex(input())` – komplexné číslo

## Pomoc

| Dátový typ | Značka |
|---|---|
| Číslo | `int` |
| Desatinné číslo | `float` |
| Reťazec | `str` |
| Logická hodnota | `bool` |

| Operátor | Význam |
|---|---|
| `+` | súčet |
| `-` | rozdiel |
| `*` | súčin |
| `/` | delenie |
| `//` | celočíselné delenie |
| `%` | zvyšok po delení |
| `**` | umocňovanie |
| `==` | porovnanie rovnosti |
| `<`, `<=` | menšie, menšie alebo rovné |
| `>`, `>=` | väčšie, väčšie alebo rovné |
| `!=` | nerovnosť |
| `=` | priradenie |
