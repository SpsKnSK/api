# Algoritmy a Python – základy

## Čo sa naučím?

Pochopím, čo je algoritmus, ako rozdeliť úlohu na menšie kroky a aký je rozdiel medzi sekvenciou, vetvením a opakovaním. Získam aj prvú predstavu o tom, čo je Python a ako vyzerá jednoduchý program.

## Prečo to potrebujem?

Pri programovaní nestačí len písať kód: najprv si musíme premyslieť, ako úlohu vyriešime. Algoritmus je plán, ktorý nám s tým pomáha.

## Tri základné myšlienky

- **Sekvencia:** kroky vykonávané za sebou, napríklad vojdeš do kancelárie, nájdeš učiteľa, požiadaš o dva fixy a vrátiš sa do triedy.
- **Vetvenie:** ďalší krok závisí od situácie. Ak je učiteľ v kancelárii, požiadaš ho o fixy; ak tam nie je, hľadáš inde.
- **Iterácia (cyklus):** ten istý krok zopakuješ viackrát, napríklad dvakrát požiadaš o jeden fix.

## Čo je Python?

Python je programovací jazyk: zapisujeme v ňom pokyny, ktoré počítač vykoná. Náš prvý program môže napríklad vypísať správu:

```python
print("Hello!")
```

Funkcia `print()` vypíše správu na obrazovku. Neskôr sa naučíme používať premenné, vstup údajov, podmienky, cykly, zoznamy a funkcie.
