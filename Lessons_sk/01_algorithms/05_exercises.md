# Precvičovacie úlohy – algoritmy

## 1. Algoritmus z každodenného života

Premyslite si každodennú činnosť (napríklad prípravu kávy alebo opravu bicykla), ktorú možno rozdeliť na kroky. Zapíšte ich a nakreslite jednoduchý vývojový diagram.

## 2. Robot a programátor

Pracujte vo dvojiciach: jeden žiak bude „robot“, druhý „programátor“. Programátor dáva jednoduché príkazy, aby robot získal fix v triede. Robot môže vykonávať iba zadané pokyny.

## 3. Prvý Python program

Vypíšte na obrazovku pozdrav `Hello!` pomocou funkcie `print()`:

```python
print("Hello!")
```

## 4. Spustenie Python súboru

1. Vytvorte nový súbor s príponou `.py`.
2. Napíšte doň riadok `print("Hello!")`.
3. Uložte súbor (`Ctrl+S`).
4. Spustite ho vo vývojovom prostredí, ktoré používate na hodine.
