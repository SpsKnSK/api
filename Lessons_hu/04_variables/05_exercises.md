# Gyakorlófeladatok – Változók

## Alapfeladatok

1. Hozz létre két-két változót az említett adattípusokból (`int`, `float`, `str`, `bool`), és írasd ki őket a `print()` függvénnyel.
2. Hozz létre szám típusú változókat, és próbáld ki rajtuk az összes bemutatott matematikai operátort.
3. Írasd ki a képernyőre legalább öt matematikai művelet eredményét a `print()` függvény segítségével.

## Összetettebb feladatok

4. Kérj be két számot, írd ki a hányadosukat három tizedesjegyre kerekítve, majd az egész osztás eredményét és a maradékot is. A program írjon magyarázó szöveget is.
   - `/`: `18 / 7 = 2.5714285714285716`
   - `//`: `18 // 7 = 2`
   - `%`: `18 % 7 = 4`
5. Írj programot a kör kerületének és területének kiszámítására. Bemenet: átmérő; a pí értéke `3.14159`. Kimeneti minta: `Az X cm átmérőjű körnek Y cm a kerülete és Z négyzetcm a területe.`
6. Kérj be két egész számot, két tizedes számot, majd két komplex számot. Mindegyik párnál írd ki az összeget és a szorzatot.
   - `int(input())` – egész szám
   - `float(input())` – tizedes szám
   - `complex(input())` – komplex szám

## Segítség

| Adattípus | Jel |
|---|---|
| Szám | `int` |
| Tizedes szám | `float` |
| Karakterlánc | `str` |
| Logikai | `bool` |

| Operátor | Jelentés |
|---|---|
| `+` | összeadás |
| `-` | kivonás |
| `*` | szorzás |
| `/` | osztás |
| `//` | egész osztás |
| `%` | maradék |
| `**` | hatványra emelés |
| `==` | egyenlőségvizsgálat |
| `<`, `<=` | kisebb, kisebb vagy egyenlő |
| `>`, `>=` | nagyobb, nagyobb vagy egyenlő |
| `!=` | nem egyenlő |
| `=` | értékadás |
