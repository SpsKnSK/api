# 💥 Rontsátok el!

Másold ki a programot, futtasd le, majd szándékosan ronts el benne egy-egy sort. Minden módosítás után figyeld meg a hibaüzenetet.

```python
print("Szia világ")
print(123)
print("Kész!")
```

Próbáld ki például ezeket:
- töröld az egyik zárójelet;
- hagyj le egy idézőjelet;
- írd át a függvény nevét nagy kezdőbetűs `Print` alakra;
- írd ki a `Szia világ` szöveget idézőjelek nélkül.

Olvasd el a hibaüzenetet: melyik sorra mutat, és mi a hiba neve?
