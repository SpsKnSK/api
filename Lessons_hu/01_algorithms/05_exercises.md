# Gyakorlófeladatok – algoritmusok

## 1. Mindennapi algoritmus

Gondoljatok egy mindennapi tevékenységre (például kávéfőzésre vagy biciklijavításra), amelyet lépésekre lehet bontani. Írjátok le a lépéseket, majd rajzoljatok hozzá egyszerű folyamatábrát.

## 2. Robot és programozó

Dolgozzatok párban: az egyik tanuló a „robot”, a másik a „programozó”. A programozó adjon egyszerű parancsokat a robotnak, hogy szerezzen be egy filctollat a teremben. A robot csak a kapott utasításokat hajthatja végre.

## 3. Első Python-program

Írjátok ki a képernyőre a `Hello!` üdvözletet a `print()` függvénnyel:

```python
print("Hello!")
```

## 4. Python-fájl futtatása

1. Hozzatok létre egy új fájlt `.py` végződéssel.
2. Írjátok bele a `print("Hello!")` sort.
3. Mentsétek el a fájlt (`Ctrl+S`).
4. Futtassátok le az órán használt fejlesztői környezetben.
